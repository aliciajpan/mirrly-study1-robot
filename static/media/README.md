# Media Files

Place your media files in these directories:

## Video
- `video/countdown_video.mp4` - Countdown video for countdown_gesture

## Images
- `image/diamond.jpeg` - Diamond image for show_diamond gesture
- `image/star.jpeg` - Star image for show_star gesture

## Supported Formats
- **Videos**: mp4, avi, mov, mkv, wmv (any VLC-supported format)
- **Images**: jpeg, jpg, png, bmp, gif

## Usage
These files are automatically referenced by their corresponding gestures. Just place the files in the correct locations and the gestures will find them.
